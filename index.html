In brief

The four systems at a glance.

Built for my own businesses and running in production today. The same approach is available for yours.

Outreach that sorts its own replies

n8n · PostgreSQL · LLM reply classification

Problem. Cold outreach for two businesses needed sending, follow-ups and reply sorting by hand.

Built. Send sequences, an LLM that labels each reply as interested, not interested or referral, automated follow-up routing and BCC logging.

Result. Live for two businesses with no manual triage.

A video factory with no operator

Remotion · Node.js · edge-tts · LLM scriptwriting

Problem. Producing short videos at volume meant a person at every stage.

Built. An LLM writes each script, edge-tts voices it, Remotion renders it, and the result publishes itself.

Result. Batches of 100+ videos with zero manual intervention per run.

GPU work without a GPU server

Modal · Python · FLUX · Whisper · n8n

Problem. Image generation and captioning need GPUs that would sit idle between jobs.

Built. n8n starts serverless GPU jobs on Modal: FLUX for images, Whisper for captions. Outputs post themselves.

Result. Images and captions generated on demand and cross-posted to several platforms automatically.

A live AI product, end to end

Claude API · Supabase · TypeScript · PostgreSQL

Problem. Checking content against policy frameworks was slow and inconsistent by hand.

Built. A full-stack tool: TypeScript frontend, Supabase auth, PostgreSQL data layer, Claude API analysis and automated email notifications.

Result. Live deployment serving real users.

Questions

Common questions.

What can be automated with AI?

Repetitive work that follows rules but needs judgement on text: sorting replies, sending outreach, producing and publishing content, and moving data between tools. If you repeat the same task more than a few times a week, it is a candidate.

Which tools do you use?

n8n for orchestration, the Claude API and other LLMs for language tasks, PostgreSQL or Supabase for data, and Modal for GPU jobs. I build around the tools you already use.

How much does an automation project cost?

Projects start from NZ$1,500. The final price is fixed after a 30-minute call and a written scope, so you know the cost before any work starts.

Do you work outside Auckland?

Yes. I am based in Auckland, New Zealand, and work remotely with clients elsewhere.

Who owns the finished workflow?

You do. I hand over the workflows with notes on how they run, so you are not tied to me to keep them going.

Are the case studies real?

Yes. Each of the four systems shown is one I built and run myself.
